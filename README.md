# compraventacafe

Software a medida de venta y compra de cafe para "Compra de Cafe el Rey David".
Herramienta interna, interfaz en espanol.

Rails 8.1 · Ruby 3.4 · PostgreSQL 18 · Hotwire · Tailwind · Pundit · RSpec

## Empezar

El desarrollo ocurre dentro de WSL (Ubuntu), sin Docker:

```bash
git clone https://github.com/LagosTech2000/compraventacafe.git ~/code/compraventacafe
cd ~/code/compraventacafe
bash scripts/bootstrap.sh
```

- Montaje y operacion del ambiente: `docs/2026-09-26/AMBIENTE.md` (solo en local, no se sube al repositorio)
- Convenciones, modelo de permisos y puntos abiertos: [`CLAUDE.md`](CLAUDE.md)
